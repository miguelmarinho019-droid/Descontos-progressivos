# Modo de uso 👇🛍️✅
Digite o valor da compra, e com base nele será aplicado o desconto que funciona de forma progressiva. Ou seja, quanto maior o valor, maior será o desconto sobre ele.
# Como funciona ⁉️🧠
Ele utiliza uma estrutura com condicionais encadeadas. Que consiste em que: Se o valor da compra for abaixo de 200, recebe um desconto de 5%. Caso não seja, se for menor que 300, recebe um desconto de 10%. Caso não seja, recebe um desconto de 15%.
Ao receber o valor e a porcentagem a qual ele tem de desconto, a fórmula de porcentagem é aplicada que é (porcentagem / 100) * (valor das compras).
Concluindo está operação, temos o valor do desconto. Agora, temos que subtraí-lo com o valor das compras para receber o valor total com o desconto aplicado que se da pela operação entre variáveis : valor_das_compras - desconto.
Com o resultado em mãos, basta mostrar ao usúario de forma simples o total que ele deve pagar.
